# 📝 To-Do List

A simple, modern and responsive **To-Do List Web Application** built using **HTML, CSS, and JavaScript**.

## 🔗 Live Demo =>  https://aritraghorai053.github.io/To-Do-List-Basic/

## 📸 Screenshot

![To-Do List Screenshot](./images/todo-screenshot.png)

## ✨ Features

* ➕ Add new tasks
* ⌨️ Add tasks using the **Enter key**
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 📊 Task progress tracking
* 🌙 Dark mode
* 📱 Responsive design
* 🎨 Clean and user-friendly UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 Run Locally

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

2. Open the project folder.
3. Open `index.html` in your browser.

You can also use **Live Server** in VS Code.

## 🎯 How to Use

1. Enter your task in the input box.
2. Click **Add** or press **Enter**.
3. Click a task to mark it as completed.
4. Delete tasks when they are no longer needed.
5. Use the dark-mode switch to change the theme.
6. Track your completed tasks using the progress bar.
